# Post hoc ordering and RPPA aggregate

Run the base `reproduce.py` first. Required generated inputs, relative to the repository root:

- `results/null/discovery95_scores.csv`
- `results/null/external138_scores.csv`
- `results/rppa/RPPA_Hallmark_patient_scores.csv.gz`
- `results/rppa/RPPA_Hallmark_dependent_correlations.csv`

Execute `python extensions/v17_review/reproduce_v17.py`. Outputs are written to `results/v17_review/`. This re-runs 2,000 patient bootstrap replicates with shared patient indices for 25 fixed RPPA sets and the RNA ordering comparison. It is conditional on the fixed scores and scales generated by the original pipeline. Expected: discovery 656/4,465 discordant patient pairs and 20/24 highest-quartile retention; external 1,888/9,453 and 26/35; RPPA median 0.160644, percentile interval 0.119170–0.192480. Bootstrap values can differ at machine precision across software versions. RPPA does not measure the source48 signature.

## Rebuild Figures 1–5 used in the current manuscript

After the base analysis and `reproduce_v17.py` have completed, run from the repository root:

    python extensions/v17_review/render_manuscript_figures.py . results/manuscript_figures

This uses the newly generated base results and `results/v17_review/main_ordering_tradeoff.csv`, writes the current manuscript's five multi-panel figures and their source/alignment records, and also writes the two Figure 2 point-label tables. The base `reproduce.py` output figures are an earlier layout and should not be substituted for the current manuscript figures. In the 2026-10-31 local verification, all five 300-dpi manuscript preview PNGs matched the supplied manuscript previews byte for byte; PDF binary hashes are not asserted to match because metadata and rendering can vary.
