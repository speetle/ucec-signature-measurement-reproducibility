# 共同23成员分析复现扩展

此扩展从已处理的公开RNA和蛋白数据出发，重建共同成员、匹配参照及汇总结果。共同成员按三个数据集可测性事后筛选；宫颈癌分析是跨癌种探索，不能作为预设29成员的独立确认。

在 Python 3.12 环境安装 `requirements.txt`。先按主仓库说明获取并准备 `input/discovery` 和 `input/external`；再运行 `python 获取宫颈癌附件.py 附件路径.xlsx`，脚本下载出版方附件并校验长度及 SHA-256。使用 `python 串联复现.py 任意路径 --release 主仓库路径 --cervical 附件路径.xlsx --work 新的空目录` 运行；结果写入该工作目录的 output。已有目录非空时程序不会覆盖。

2026-11-08 的测试基于远程提交 7a9e8bb 的稀疏检出、从 LinkedOmics 重新下载并校验的外部数据、出版方重新下载并校验的宫颈癌附件；生成的结果、成员映射和汇总与既有版本逐表一致。最新版外部输入重建脚本与旧版 SHA-256 一致，使用新版脚本重建的三份矩阵与此前逐表一致。该测试未从原始测序或质谱重建，也未在另一台机器运行。

本扩展不附带第三方矩阵或出版方附件。来源与使用边界见主仓库 THIRD_PARTY_DATA.md 和本扩展的附件获取与校验.md；获取材料不自动授予再分发权限。

本入口目前重建共同背景下两个子宫内膜癌队列的匹配参照结果；它不生成三队列配对 bootstrap 区间、宫颈癌队列结果、整合图或整篇论文其他分析，因此不能作为全文复现入口。扩展属于已观察结果后的探索分析。
